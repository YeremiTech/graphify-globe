Benchmark de navegador (manual / semi-automático)

Este harness mide importación en el hilo principal + FPS aproximado con Three.js mínimo. No sustituye la app completa; sirve para comparar hosts/navegadores con el mismo archivo sintético.

No declares soporte para un tamaño si no lo corriste aquí o en la suite Node en este dispositivo.

  1. Genera un grafo: npm run bench:generate -- --nodes 5000 --density medium
  2. Abre esta página con npm run bench:browser
  3. Selecciona el JSON generado
  4. Copia el reporte JSON al final
